# 2026 深圳医师定期考核临床类别复习助手 — 软件设计文档

- 文档状态：已确认，可进入实施计划阶段
- 日期：2026-10-05
- 首发题库：2026 年深圳医师定期考核临床类别题库，共 500 道单选题
- 交付形式：每套题库一个独立固定网址，移动端、平板和桌面浏览器通用
- 架构原则：零应用后端、零买家账号、零跨设备同步、本地优先

## 1. 背景与目标

本产品面向准备参加医师定期考核业务水平测评理论考试的考生，用于题库浏览、做题、模拟考试和错题复习。首发版本完成一个独立题库网页；后续题库复用同一套程序架构，但各自构建为独立网址，数据和进度互不关联。

核心目标：

1. 买家通过固定网址点开即用，无需安装复杂软件，也可添加到手机主屏幕。
2. 手机优先，兼容平板和电脑，常用操作不依赖鼠标悬停。
3. 第一次联网打开后缓存题库和程序，使用中短暂断网仍可继续刷题。
4. 所有个人进度保存在当前设备，不上传、不注册、不登录。
5. 题库生产由开发侧完成，卖家只需提供原始题库并接收发布网址。
6. 每个题库完全独立，不能从一个题库切换到另一个题库。

## 2. 已确认决策

- 采用零应用后端架构，不使用登录、激活码、云数据库、云函数或在线支付接口。
- 使用免费静态托管；首发使用 Cloudflare Pages 提供的免费 `*.pages.dev` 子域名。
- 发布账户和网址归卖家所有，开发侧只获得发布操作权限，不将发布凭据写入代码。
- 买家进度、设置、错题和考试记录只保存在当前浏览器设备。
- 每套题库拥有唯一 `bankId`、独立项目、独立网址和独立本地数据库。
- 不再设计面向卖家的 Word 自动解析工具或导入界面。
- 卖家提供原始题库后，由开发侧完成清洗、去重、答案校验、解析生成、结构化入库、构建和发布。
- Word 原题不包含解析；解析由 AI 在发布前生成，不经过人工逐题审核，页面明确标注“AI 辅助解析，仅供复习参考”。
- 首发版本完整支持单选题；数据结构预留多选题、判断题和案例分析题扩展能力。
- 闲鱼只承担成交和发给买家网址，不在应用内处理付款。

## 3. 范围

### 3.1 首发范围

- 题库首页与学习统计。
- 背题模式。
- 做题模式。
- 模拟考试。
- 错题集及可配置的移出规则。
- 本地智能搜题。
- 当前设备的学习进度和考试记录。
- PWA 离线缓存与版本更新提示。
- 独立的题库构建配置和部署流程。
- 首次打开的数据本地保存提示和 AI 解析免责声明。

### 3.2 非目标

- 不做买家账号、购买校验、设备绑定和跨设备同步。
- 不做应用内付款、订单系统或自动发货。
- 不做在线题库管理后台或卖家导入工具。
- 不做买家提交纠错、评论或客服聊天功能。
- 不在首发版本中实现多选题、判断题和案例分析题的完整作答界面。
- 不保证浏览器数据被清除、设备损坏或更换浏览器后能够恢复进度。
- 不使用官方协会、考试机构或政府部门的名称、徽标或资质暗示。

## 4. 用户与职责

### 4.1 买家

买家通过闲鱼获得一个固定网址，在浏览器中直接使用。买家不需要注册，不需要输入激活码，也不能切换题库。

### 4.2 卖家

卖家持有托管账户、网址和题库销售授权，决定题库版本、售价、上架文案和售后规则。卖家不需要操作代码或本地导入工具。

### 4.3 开发侧

开发侧负责从 Word 原始资料生成规范化题库，使用 AI 补充解析，执行质量检查，构建静态 PWA，并在获得授权的发布账户下部署新版本。

## 5. 核心功能需求

### 5.1 首页与学习统计

首页显示题库名称、题库版本、总题数、已完成题数、正确率、错题数量和最近一次模拟考试结果。主入口包括：

- 继续学习
- 背题模式
- 做题模式
- 模拟考试
- 错题集
- 智能搜题

首次进入时显示一次提示：学习数据仅保存在当前浏览器设备，清除浏览器数据后将无法恢复。

### 5.2 背题模式

- 题目和全部选项直接显示。
- 正确答案默认高亮。
- 解析默认展开，可在设置中选择默认折叠。
- 支持上一题、下一题、顺序模式、随机模式和恢复上次位置。
- 背题模式不改变错题集，不参与正确率统计。
- 用户可按题号快速跳转。

### 5.3 做题模式

- 用户选择一个答案并确认后，立即显示正确或错误结果。
- 显示正确答案和解析。
- 单选题未选择答案时不能提交。
- 答错自动加入错题集。
- 支持顺序和随机模式；顺序模式保存当前位置，随机模式保存本次队列。
- 记录该题最新作答结果，并更新已完成题数和正确率。
- 用户可以在设置中开启或关闭答对后的自动跳题；默认关闭，避免误操作。

### 5.4 模拟考试

- 从题库中随机抽取 100 道单选题，不重复。
- 考试时间 60 分钟，每题 1 分，总分 100 分。
- 60 分及以上为及格。
- 考试过程中不显示正确答案和解析。
- 用户可前后切题、修改答案，并通过答题卡查看已答和未答题号。
- 计时以考试结束时间戳为准，刷新、息屏或关闭页面后再次打开仍继续计时。
- 时间到后自动交卷。
- 主动交卷前弹出确认框，并明确提示未答题数。
- 交卷后统一显示全部题目的用户答案、正确答案和解析。
- 答错题目自动加入错题集。
- 可随时开始新的模拟考试；历史考试记录保留在本地。
- 若题库中的单选题不足 100 道，构建阶段默认拒绝发布模拟考试模式，必须由开发侧显式修改题库配置后才能使用不足题数的考试。

计分公式：`四舍五入(答对题数 ÷ 考试题数 × 100)`。当前题库固定为 100 题，因此一道题对应一分。

### 5.5 错题集

- 做题模式和模拟考试中的错题自动进入错题集。
- 背题模式不会自动加入错题集。
- 用户可选择以下移出规则：
  - 答对一次后移出
  - 连续答对三次后移出
  - 只能手动移出
- 默认规则为“连续答对三次后移出”。
- 答错后连续答对次数归零，并更新最近答错时间。
- 错题集可按题型、最近答错时间和累计答错次数排序。
- 支持单题移除和一键清空，清除前需要二次确认。

### 5.6 智能搜题

检索范围仅包括：

- 题干
- 选项内容
- 正确答案文本

解析不参与检索。

搜索能力：

- 忽略中英文空格、常见标点和大小写。
- 支持常见错别字和有限近义表达。
- 搜索在本地执行，不向任何服务器发送关键词。
- 结果显示命中题目、命中字段和简短摘要。
- 点击结果直接进入该题的背题详情。
- 近义词和易错词由发布前构建流程生成并随题库缓存，不在运行时调用 AI。

### 5.7 设置与数据

- 字体大小：小、中、大，默认中。
- 错题移出规则。
- 背题解析默认展开或折叠。
- 做题答对后是否自动跳题，默认不跳。
- 查看题库版本、构建日期和题目数量。
- 清除本机学习进度、错题和考试记录，执行前二次确认。
- 显示“数据仅保存在本设备、不会自动同步”的永久说明。
- 首发不提供跨设备备份和恢复。

### 5.8 PWA 与更新

- 支持安装到 Android 主屏幕、iPhone/iPad 主屏幕和桌面浏览器。
- 首次加载后缓存应用外壳、题库数据、搜索索引和静态资源。
- 无网络时，已缓存题库的背题、做题、错题复习和已开始考试可继续使用。
- 检测到新版本时显示“有新版本，刷新后更新”，不强制中断正在进行的考试。
- 更新程序或题库时不删除用户进度。
- 如果数据结构升级，使用版本化迁移；迁移失败时保留旧数据并提示用户，不静默清空。

## 6. 数据模型

所有题目 ID 在同一个题库内永久稳定。题干修正不得改变题目 ID，以保证进度和错题记录不丢失。

```ts
type QuestionType = 'single' | 'multiple' | 'judge' | 'case'

interface QuestionOption {
  key: string
  text: string
}

interface Question {
  id: string
  type: QuestionType
  stem: string
  options: QuestionOption[]
  answer: string[]
  answerText: string
  explanation: string
  explanationSource: 'provided' | 'ai' | 'edited'
  searchTerms: string[]
  revision: number
}

interface BankConfig {
  bankId: string
  title: string
  version: string
  buildDate: string
  questionCount: number
  examQuestionCount: number
  examDurationMinutes: number
  passScore: number
  primaryType: QuestionType
  disclaimer: string
}
```

首发数据约束：

- `type` 固定为 `single`。
- `answer` 数组长度为 1，值为正确选项的 `key`。
- 每题至少有两个选项。
- `answer` 必须指向真实存在的选项。
- `explanation` 必须非空。
- `searchTerms` 由构建流程生成并缓存。

本地数据结构：

```ts
interface QuestionProgress {
  questionId: string
  answered: boolean
  lastCorrect: boolean
  correctCount: number
  wrongCount: number
  lastAnsweredAt: number
}

interface WrongRecord {
  questionId: string
  wrongCount: number
  consecutiveCorrect: number
  lastWrongAt: number
}

interface ExamSession {
  id: string
  startedAt: number
  endsAt: number
  submittedAt?: number
  questionIds: string[]
  answers: Record<string, string[]>
  score?: number
  passed?: boolean
}

interface UserSettings {
  schemaVersion: number
  fontSize: 'small' | 'medium' | 'large'
  wrongRemovalRule: 'once' | 'threeTimes' | 'manual'
  explanationExpanded: boolean
  autoNextAfterCorrect: boolean
}
```

IndexedDB 数据库名格式：`medquiz__<bankId>__v1`。对象仓库包括 `settings`、`progress`、`wrongBook`、`examSessions`、`studySessions`。不同题库使用不同数据库名，保证数据隔离。

## 7. 技术架构

前端沿用现有 React、TypeScript、Vite 和 Tailwind CSS 初版作为基础，重构为可配置、可离线、多题库独立构建的静态 PWA。

```mermaid
flowchart LR
    A[Word 原始题库] --> B[开发侧题库构建流程]
    B --> C[规范化 questions.json]
    C --> D[解析生成与质量校验]
    D --> E[独立题库构建]
    E --> F[静态 PWA 资源]
    F --> G[Cloudflare Pages 免费网址]
    G --> H[买家手机/平板/电脑浏览器]
    H --> I[IndexedDB 本地进度]
```

分层设计：

- 数据层：静态题库 JSON、题库配置、搜索索引。
- 领域层：答题判定、错误集规则、考试计分、计时与状态迁移。
- 持久化层：IndexedDB 和版本迁移。
- 界面层：响应式页面、题目组件、考试答题卡、设置和统计。
- PWA 层：Manifest、Service Worker、缓存版本和更新提示。
- 构建层：每个 `bankId` 单独构建，生成独立部署目录。

关键工程约束：

- 题库数据不得硬编码在页面组件中。
- 每个构建只包含一个题库，买家界面不存在题库切换入口。
- 后端地址、账户信息和发布令牌不得进入客户端构建产物。
- 组件不得直接读写 IndexedDB，必须通过统一仓储接口。
- 模拟考试和错题规则必须使用纯函数实现，便于单元测试。

## 8. 题库生产与发布流程

### 8.1 输入

卖家提供 Word 原始题库。当前 Word 的结构为：

1. 题号加题干。
2. `A.` 到 `E.` 的选项。
3. `校核答案：字母`。
4. 不包含解析。

开发侧可以人工处理个别格式差异，但最终必须转成统一结构化数据。

### 8.2 构建步骤

1. 解析 Word 中的题号、题干、选项和答案。
2. 去除重复空格、不可见字符和错误编号。
3. 检查选项缺失、答案无对应选项、重复题干和题目数量异常。
4. 对缺少解析的题目生成 AI 解析。
5. 检查解析非空、长度合理，并且不与正确答案明显矛盾。
6. 生成题干、选项、正确答案和近义词的本地搜索索引。
7. 写入规范化题库 JSON 和题库构建配置。
8. 执行单元测试、内容校验和浏览器构建。
9. 发布到该题库对应的 Cloudflare Pages 项目，保持原网址不变。
10. 将固定网址、版本号和主要更新内容交给卖家。

### 8.3 AI 解析规则

- 解析使用简洁、面向复习的中文，通常为 40 至 160 字。
- 优先解释正确答案为什么正确，并简要排除主要干扰项。
- 涉及医学事实时避免臆造指南、文献、机构或未提供的年份。
- 不声称是官方解析，不使用“官方答案”“考试原题”等表述。
- 页面显示“AI 辅助解析，仅供复习参考”。
- 解析生成在发布前完成，买家使用时不会调用 AI，也不会产生运行费用。

### 8.4 发布账户

- Cloudflare 账户、项目和免费网址由卖家持有。
- 首次发布时，卖家在受控环境中完成一次登录授权。
- 开发侧使用授权发布，不接触卖家密码。
- 发布令牌仅保存在本机环境变量或本地凭据存储中，不提交到 Git。
- 卖家可随时撤销授权并收回全部发布权限。

### 8.5 命名与网址

- 首发题库 `bankId`：`sz-clinical-2026`。
- 默认产品名：“2026 深圳医师定期考核临床类别复习助手”。
- Cloudflare Pages 项目名优先使用 `sz-clinical-2026-review`。
- 如果免费子域名已被占用，依次使用 `sz-clinical-2026-review-01`、`-02`，确定后永久保持不变。
- 后续题库使用独立 `bankId` 和独立 Pages 项目，不共享网址、题库数据或本地数据库。

### 8.6 售卖与交付

- 闲鱼商品定位为“复习练习资料”或“模拟刷题工具”，不使用官方合作、考试原题、包过或权威认证等表述。
- 买家成交后收到一个固定网址和使用说明，不需要账号、激活码、下载安装包或付款接口。
- 使用说明包含：手机浏览器打开、收藏网址、添加到主屏幕、进度仅保存在当前设备以及清除浏览器数据后的影响。
- 更新题库时保持原网址不变，买家刷新页面或更新 PWA 缓存后使用新版本。
- 当网址暂时不可访问时，卖家先确认静态托管状态和当前发布版本；不要求买家提供账号或个人信息。
- 因为零后端，售后规则中应明确“不能阻止网址转发”和“不能跨设备找回进度”，并在上架页面提前说明。

## 9. 界面设计

### 9.1 视觉方向

- 风格：专业、清晰、轻量，不模仿官方考试系统。
- 主色：深青蓝；正确为绿色，错误为红色，解析提示为琥珀色。
- 避免使用红色大面积作为主色，减少考试焦虑感。
- 字体使用系统字体，保证中文字符在不同设备上清晰。
- 题目正文允许用户切换字号，长题干自动换行，不横向滚动。

### 9.2 响应式导航

- 手机：底部导航，提供首页、刷题、搜题、我的四个入口；考试时进入沉浸式页面。
- 平板：左侧精简导航加主内容区。
- 电脑：左侧导航、较宽题目区和可选答题卡侧栏。
- 主要点击区域不小于 44 × 44 CSS 像素。
- 键盘用户可使用数字键或字母键选择答案，使用方向键切题。

### 9.3 核心页面

1. 首页：题库信息、统计、六个功能入口。
2. 刷题设置：选择背题或做题、顺序或随机、继续上次进度。
3. 答题页：题号、题干、选项、解析和操作按钮。
4. 考试页：倒计时、答题区、答题卡、交卷按钮。
5. 考试结果页：分数、是否及格、正确率、错题数、逐题解析。
6. 错题集：排序、筛选、设置移出规则和开始错题复习。
7. 搜题页：搜索框、命中结果和跳转入口。
8. 设置页：字号、行为设置、版本、免责声明和清除数据。

## 10. 错误处理

- 题库数据损坏：阻止进入相关功能，显示“题库数据异常，请更新页面”，保留已有本地进度。
- 本地存储不可用：允许临时刷题，但明确提示进度无法保存。
- 本地存储空间不足：停止自动保存并提示清理数据或切换浏览器。
- 考试状态损坏：允许放弃当前考试并重新开始，不删除历史错题。
- PWA 更新失败：继续使用旧缓存，不强制白屏。
- 搜索索引缺失：退化为题干和选项的普通关键词匹配。
- AI 解析生成失败：构建停止并输出具体题号，不允许发布空解析版本。
- 部署失败：保留上一已发布版本，不覆盖原网址上的可用版本。
- 用户设备时间异常：倒计时使用开始时间与结束时间差值计算，并使用单调时钟修正页面运行中的时间跳变。

## 11. 安全、隐私与合规

- 应用不收集姓名、手机号、身份证号、位置或健康信息。
- 搜索词、作答记录和考试记录不上传。
- 买家之间不共享数据，同一浏览器的不同题库也不共享数据。
- 静态网站头设置禁止被错误站点框架嵌套，并启用合理的内容安全策略。
- 网址转发、源码提取和题库复制的技术风险无法通过零后端方案阻止，卖家和开发侧均需知情。
- 页面不使用医学诊断承诺，不宣传“包过”“原题”“官方认证”。
- 商品详情使用“复习练习资料”“模拟刷题工具”等表述，并附 AI 解析提示。
- 卖家需要保留题库来源、购买授权或原创证明。

## 12. 测试与验收

### 12.1 自动化测试

- 题库解析：题号、选项、答案和重复题目识别。
- 数据校验：答案越界、空解析、题量不足和无效选项。
- 搜索：标点、空格、错别字、近义词和答案文本命中。
- 做题逻辑：答对、答错、重复作答和进度更新。
- 错题规则：答对一次移出、连续三次移出、手动模式和连续次数重置。
- 考试：随机抽题不重复、计分、及格线、倒计时恢复和到时自动交卷。
- 存储：题库隔离、数据库升级和旧数据迁移。
- PWA：离线加载、缓存更新和更新不丢进度。

### 12.2 浏览器与设备验证

- Android：Chrome 当前版本及前两个主版本。
- iPhone/iPad：Safari 当前版本及前两个主版本，最低 iOS 16.4。
- Windows：Edge 和 Chrome 当前版本及前两个主版本。
- 屏幕宽度：360、390、768、1024、1440 CSS 像素。
- 横竖屏切换、系统大字体、深色模式显示不破坏布局。
- 首次联网后开启飞行模式，验证背题、做题、错题复习和已开始考试。

### 12.3 首发验收标准

1. 500 道题全部可访问，无空选项、无空解析、无答案越界。
2. 背题、做题、模拟考试、错题集和智能搜题全部可用。
3. 模拟考试随机抽取 100 道题，60 分钟，60 分及格，到时自动交卷。
4. 交卷后可以查看全部正确答案和解析。
5. 错题按用户配置的规则移出。
6. 搜题覆盖题干、选项和正确答案，不搜索解析。
7. 刷新页面后进度、错题和考试记录保留。
8. 第一次联网打开后，短暂断网仍可完成主要学习功能。
9. 手机、平板和电脑布局无明显溢出、遮挡或不可操作区域。
10. 不同题库构建使用不同网址和 IndexedDB 数据库，不能互相切换或读取数据。

## 14. 主要风险与处理

- 网址转发风险：零后端无法阻止。仅在商品页如实说明，不承诺设备绑定。
- 浏览器清数据风险：首次进入明确提示；首发不提供云恢复。
- AI 解析错误风险：页面标注 AI 辅助解析、仅供参考；保留题库版本，卖家可要求重新生成并发布。
- 免费托管可访问性风险：上线前测试不同网络；如果长期不可接受，再评估自有域名或更换静态托管，但不改变零后端架构。
- 更新缓存滞后风险：每次发布提升 Service Worker 版本，提示用户刷新；如果题库关键错误，及时发布修复版本。
- 题库版权风险：只有获得原创、购买授权或明确转售许可的题库才可发布。

# 买家使用说明

## 使用方式

1. 使用卖家提供的固定网址，在手机、平板或电脑浏览器中打开。
2. 第一次使用需要联网，题库缓存完成后，短暂断网也可以继续刷题。
3. 手机或平板可点击浏览器菜单中的“添加到主屏幕”，以后像应用一样打开。
4. 做题模式、模拟考试中的错题会自动保存在当前设备。
5. 学习进度、错题、设置和考试记录只保存在当前浏览器设备，不会自动同步到其他设备。

## 重要提示

- 清除浏览器数据、使用无痕模式、更换浏览器或更换设备可能导致进度无法恢复。
- 模拟考试为随机 100 道单选题，60 分钟，60 分及格，到时自动交卷。
- 搜题支持题干、选项和正确答案，不检索解析。
- 页面解析由 AI 辅助生成，仅供复习参考，不作为官方答案或医疗建议。
- 如遇网址无法打开，请先检查网络，再联系卖家确认当前题库版本。
